#  End-to-End Chest Cancer Detection using MLflow & DVC

An end-to-end **Chest Cancer Classification System** built using **Deep Learning (CNN)** and **MLOps tools** like **MLflow** and **DVC**.

This project automates the complete machine learning lifecycle — from **data ingestion** to **model training, evaluation, experiment tracking, and reproducible pipelines**.  
It follows **industry-standard MLOps practices** and is designed to be **scalable, reproducible, and production-ready**.

## ⚙️ Installation

### 1. Clone the repository
```bash
git clone https://github.com/SrishtiSingh100/End-to-End-Chest-Cancer-Classification-using-MLflow-DVC.git
cd End-to-End-Chest-Cancer-Classification-using-MLflow-DVC

 2. Create virtual environment
conda create -n chestmlops python=3.10 -y
conda activate chestmlops

3. Install dependencies
pip install -r requirements.txt

Advantages

The user does not need to manually run individual ML steps.

The entire workflow is fully automated, reproducible, and version-controlled.
Users can retrain, evaluate, and compare models with a single command, making the system suitable for real-world ML production environments.
